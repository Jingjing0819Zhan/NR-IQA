# E001：RALI 固定小子集评估

状态：待 E000 成功后准备。

## 问题

模型的质量排序与人类评分是否一致？先建立可靠评估流程，再分析分歧。

## 初始设计

- 数据：作者 README 指向的 Data-DeQA-Score / KONIQ 测试元数据。
- 样本：核对训练范围与划分后固定抽取约 100 张，随机种子 42。
- 输入名单放 `manifests/`，保留标签字段及来源说明。
- 沿用作者预处理和模型权重，先不加自定义退化。
- batch size 从 1 开始，先验证正确性。

## 输出

逐图预测、对应人类标签、样本数量、原始 PLCC、SRCC。若计算 MAE，先确认两边评分尺度一致。

## 检查

- 输入输出名单一致，没有缺图、重复或静默跳过。
- 指标用 SciPy 复算，按图片标识关联预测和标签。
- 小子集用于开发，不拿其结果直接宣称复现论文全测试集。
- 人工修改图片后不能沿用原图 MOS。

## 下一步

扩大到完整协议评估，查看稳定失败现象，再决定是否进入专家互补性预研。
