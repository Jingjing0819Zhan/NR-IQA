## 晚上：独显主机执行

### 1. 同步与环境

先 `git status`，处理本地未完成工作，再 `git pull --ff-only`。选择已配置 RALI 附加依赖的解释器，记录其路径。推荐独立环境 `.venv-rali`，不直接改动原 pyIQA 环境。

RALI 作者的 setup.sh 只包含 transformers==4.51.3、joblib、scikit-learn 的安装命令，并不负责完整配置 Python、GPU、PyTorch。附加清单见 environment/requirements-rali-extra.txt；PyTorch 安装按主机已验证方案另行处理。

### 2. 作者代码与权重

- 作者代码：https://github.com/xuanyuzhang21/RALI
- RALI 权重：https://huggingface.co/ByteDance/Q-Insight/tree/main/RALI
- 对应目录：ckpt.pt、pca.pkl、basis.npz、best/ 及其配套文件。
- 配置中的默认作者目录为 `D:/NR-IQA-baselines/RALI`，权重为项目中的 `checkpoints/RALI`。
- 权重和代码版本实际准备完成后再记录，不预填成功状态。

### 3. 检查输入

在项目根目录的 PowerShell 终端运行，解释器路径按实际环境替换：

```powershell
.\.venv-rali\Scripts\python.exe scripts\run_rali_single.py --check-inputs
```

若输入缺失，按清单补齐。这条命令不导入 PyTorch，不创建记录目录。路径通过仍不能代替权重完整性和依赖验证。

### 4. 实际执行

```powershell
.\.venv-rali\Scripts\python.exe scripts\run_rali_single.py
```

配置默认要求 CUDA，若不可用会明确报错。脚本先预热，再对同一图片评分三次。运行结果保存至 `experiments/E000/records/<唯一编号>/`。

### 5. 检查与交接

- 查看 metadata 的 status、解释器、GPU、版本和 Git commit。
- 检查 load.log 中是否有 PCA、原型加载失败，不能忽略 fallback。
- 检查分数为有限值，记录重复差异。
- 计时不包括模型加载或读图，只是初步检查。
- 更新 conclusion.md、experiment_index.csv、notes/handoff.md。
- 检查记录中的本机路径等内容后，由你手动提交、推送。
